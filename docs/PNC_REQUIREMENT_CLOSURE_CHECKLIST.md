# PNC Requirement Closure Checklist

This checklist tracks the remaining requirements before submitting to Photonic Network Communications.

Status: mostly complete.

Completed:

- .gitignore strengthened.
- requirements-lock.txt added.
- Smoke test added and passed.
- Generated environments, pycache files and Joblib models removed from Git tracking.

Remaining:

- Create versioned release after final manuscript freeze.

## 2. Manuscript identity

Status: in progress.

Final safe identity:

A calibrated surrogate framework for PCS trend evaluation in coherent optical link scenarios.

Do not frame the paper as:
- a fully physical Manakov/NLSE SSFM simulator;
- a raw GNPy-validated simulator;
- an experimental or field-validated study.

Allowed wording:

The framework is evaluated using repeated-seed stability tests and external GNPy-based calibration diagnostics. Raw absolute GSNR differs from GNPy by a conservative near-constant offset, while offset-calibrated span trends agree within sub-dB error.

## 3. Physical model clarification

Status: not fully complete.

Required manuscript action:
- State clearly that the current waveform/SSFM-like component is a normalized calibrated surrogate.
- Explain that dispersion, nonlinearity and noise scaling are effective parameters.
- Avoid claiming direct physical Manakov/NLSE propagation unless a physical implementation is added.

## 4. Independent validation

Status: partial.

Current supported evidence:
- C-band stronger stability test passed.
- Day-11 raw GNPy reference failed.
- Day-12 showed mostly constant conservative offset.
- Day-13 offset-calibrated diagnostic passed with calibrated RMSE 0.284458 dB and LOO RMSE 0.379277 dB.
- Earlier C/S/C+S calibrated validation evidence exists but must be integrated carefully.

Remaining:
- Add independent cases across span count.
- Add independent launch powers beyond calibration powers.
- Add channel-loading variation.
- Add baud-rate variation if feasible.
- Add fiber-parameter variation if feasible.
- Add one public benchmark or external dataset if available.

## 5. Novelty clarification

Status: not complete.

The novelty should be written as:
- reproducible calibrated surrogate evaluation workflow;
- PCS trend analysis under multiband coherent-link stress scenarios;
- explicit separation between raw agreement and calibrated diagnostic agreement;
- repeated-seed and symbol-count stability checks;
- transparent limitations and claim control.

Avoid vague novelty claims such as:
- "combines PCS and neural mitigation";
- "fully validates a physical simulator";
- "achieves experimental agreement."

## 6. Baselines

Status: partial or unclear.

Required baselines to document:
- uniform 16-QAM;
- PCS-only;
- neural-only mitigation if used;
- PCS plus neural mitigation if used;
- GN/GNPy uncalibrated reference;
- calibrated GNPy diagnostic;
- computational cost versus accuracy.

## 7. Manuscript formatting

Status: not complete.

Required:

## 8. Final submission gate

Submit only after:
- manuscript claims match repo evidence;
- all tables and figures can be reproduced;
- no old conference/Q2/Q3 contradictory README remains;
- no generated environments or model binaries are tracked;
- release DOI is created;
- final PDF compiles cleanly.
